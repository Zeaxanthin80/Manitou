02

Getting there from where the tree is now

If you followed the first version of this sheet, the four series are at the top level, Apparel › T-Shirts still exists, and Accessories is gone. In this order — a category cannot be deleted while anything points at it, and the portal will name what is in the way:

  1. Edit T-Shirts: set Inside to — top level —.
  2. Delete Apparel. If it refuses with “still holds 1 product”, that is the hidden T-Shirt placeholder — move it to T-Shirts first.
  3. Create Accessories again, top level, web address accessories.
  4. Edit Field Guide, Emblem, Poster and Orbit OS: set Inside to T-Shirts.
  5. Edit the Orbit OS Tote and Orbit OS Field Cap products: category Accessories. The tote also needs its visibility set back to visible — it was hidden under the old instructions.

Then the two products that were there from the start:

ProductDoWhy
Miami T-Shirt Change category to Poster It is a city plate, same as New York.
T-Shirt Set to hidden A placeholder name with no design behind it. Soft delete keeps the row.
Nothing else gets deleted. T-Shirts is a department now, and the hidden T-Shirt placeholder stays filed under it — a soft-deleted product keeps its category, and the row cannot be removed without removing order history that might one day point at it.
